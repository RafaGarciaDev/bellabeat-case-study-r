# ⌚ Estudo de Caso Bellabeat — Google Data Analytics (R)

Estudo de caso final do certificado **Google Data Analytics**: análise dos dados de atividade física do **Fitbit** (FitBase, abr–mai/2016) para orientar a estratégia de marketing da Bellabeat.

![R](https://img.shields.io/badge/R-276DC3?style=flat-square&logo=r&logoColor=white) ![tidyverse](https://img.shields.io/badge/tidyverse-1A162D?style=flat-square) ![ggplot2](https://img.shields.io/badge/ggplot2-276DC3?style=flat-square)

## 🔍 O que é analisado
- Passos, calorias e intensidade por dia e por hora
- Relação entre passos e calorias gastas
- Média de calorias por dia da semana
- Sono e frequência cardíaca

## 🛠️ Tecnologias
R · tidyverse · lubridate · janitor · skimr · ggplot2 · plotly

## ▶️ Como rodar
Abra `Google_Data_Analytics-Estudo_de_caso_Bellabeat.R` no RStudio. Os CSVs estão em `database/`.
